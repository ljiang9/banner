# banner

把文字变成大大的 ASCII 横幅。纯标准库、本地运行、零依赖。

```
$ banner "HI"

#...#  ###
#...#   #
#####   #
#...#   #
#...# #####
```

## 安装

不需要安装，Python 3.10+ 直接运行：

```bash
cd banner
python3 -m banner "HELLO"
```

## 用法

```bash
banner "文字"          # 放大文字（A-Z 0-9 及 ? ! . - + / :）
banner --char "*" "HI" # 自定义填充字符
echo "HELLO" | banner --stdin   # 从管道读取
banner --stdin         # 从标准输入读取
```

未知字符（比如中文）会自动显示为 `?` 字形，不会报错。

## 设计说明

- 内置手工绘制的 5x5 点阵字体，`#` 表示填充、`.` 表示空白，渲染时按 `--char` 替换。
- 字母自动转大写；空格保留为字间距。

## 已知局限

- **只支持拉丁字符**：A-Z、0-9 和少量符号（`? ! . - + / :`）。中文没有点阵字形，会显示为 `?`——这是架构取舍，不是 bug。
- 固定 5 行高，不支持缩放字号。
